## 🎯 My AI Testing Decision Matrix

| Task Type | Example | Recommended Tool | Why? |
|-----------|---------|------------------|-------|
| **Micro-Fix** | Fixing a typo or closing a bracket | **Ghost Text** | Fastest; no context switch needed. Inline suggestions appear immediately as you type. |
| **Logic Check** | "Why is this loop infinite?" | **Chat Mode** | Needs reasoning, not file access. Best for quick questions and explanations without modifying multiple files. |
| **New Test File** | Creating `cart.spec.ts` from scratch | **Prompt File** | Enforces team standards (RCTC - Read, Context, Task, Constraints). Ensures consistency and maintains best practices across test files. |
| **Refactoring** | Renaming `userId` to `customerId` everywhere | **Agent (@workspace)** | Needs multi-file awareness. Can search across entire codebase and make coordinated changes safely. |
| **Bug Fixing** | "Test failed with 500 Error" | **MCP Agent (Healer)** | Needs to read error logs + code. Can access terminal output, stack traces, and correlate with source code. |
