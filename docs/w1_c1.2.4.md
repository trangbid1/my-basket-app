# Week 1 - Challenge 1.2.4

## context: microservices/api-gateway/src/config.ts
## @workspace How many requests per minute are allowed before the Gateway returns a 429 error?

## Result:
- The API Gateway allows 1000 requests per 15 minutes per IP, as defined in the rate limiter configuration in index.ts. This translates to 66 requests per minute before the Gateway returns a 429 Too Many Requests error.

- Here is the relevant configuration:
const limiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15 minutes
  max: 1000, // Limit each IP to 1000 requests per windowMs
  message: 'Too many requests from this IP, please try again later.',
});
