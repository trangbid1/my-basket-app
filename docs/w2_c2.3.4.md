# Challenge 3: The "Gherkin-Only" Config

## Risk Assessment

**High**: This method modifies the internal state of the `carts` map and updates multiple properties on a `Cart` object. If not properly tested, there is a risk of unexpected behavior or data corruption.

## Gherkin Tests

```gherkin
Feature: Cart Clearing

  Scenario: Clear cart successfully
    Given the user with id "user1" has a cart with items ["item1", "item2"] and total amount $10.00
    When the cart is cleared for the user with id "user1"
    Then the cart should be empty with no items and total amount $0.00
    And the cart's updated at timestamp should be recent

  Scenario: Clear cart fails due to invalid user id
    Given the user with id "invalid" does not exist
    When the cart is cleared for the user with id "invalid"
    Then an error is thrown with message "User not found"
```
